# 账号验证管家 1.6.0 更新与验证

Windows 与 Android 的用户可见版本号已统一为 1.6.0。Windows 程序集版本为 1.6.0.0，Android versionCode 为 10601，保留原正式包名及发布签名。

## 二维码识别

| 平台 | 操作 |
| --- | --- |
| Windows | 点击“上传二维码”，选择本地图片，识别后显示当前验证码 |
| Android | 点击“拍照识别二维码”调用系统相机，确认照片后识别；或点击“上传二维码图片”从系统文件选择器选择图片 |

二维码在设备本机解码，不使用在线服务。支持纯 Base32 密钥和标准 Authenticator URI。Windows 继续支持 TOTP/HOTP，Android 继续支持 TOTP；保留 URI 的发行方、账号、算法、位数、周期及适用的计数器。生成结果沿用现有复制与最近十条加密历史。

同一图片包含多个有效 2FA 二维码时，先选择其中一条；列表不显示密钥。旋转、反色、常见 PNG/JPEG 图片纳入验证。取消选图或拍照保留当前结果；选定图片但识别失败会停用旧结果的复制按钮，不将失败输入写入历史。不支持 Authenticator 批量迁移二维码。

Android 已按最新要求恢复防截图和录屏保护：主窗口、二维码导入窗口及应用弹窗均设置 FLAG_SECURE；Android 13+ 禁用最近任务截图，复制内容恢复 IS_SENSITIVE 标记。加密历史、密码显示切换与系统级权限机制继续沿用。应用未申请网络权限、广泛存储权限或直接相机权限，拍照由系统相机处理完整照片，并在完成/取消后清理本次临时照片。

## 验证范围

当前 10601 构建的应用端安全配置与回归结果见 [安全保护恢复验证](安全保护恢复验证.md)。此前 10600 构建的记录作为历史资料保留。

- Windows：3,858 项原有核心、83 项智能解析、16 项二维码、34 项历史、38 项界面逻辑检查，共 4,029 项。
- Android：23 组单元测试；发布 Lint、R8、签名构建；独立 QA 包 76 项真机检查，设备为 OPPO PHY110 / API 37。
- 发布 Lint 为 0 错误、2 个版本更新提示（Gradle 与 AndroidX core）；本次没有升级构建工具链。
- 真机新增检查包含上传返回图片、完整照片 URI 写入与解码、参数保留、验证码、加密历史、取消操作、无效二维码清旧结果、防截图和敏感剪贴板标记。
- 自动化用生成的测试图片模拟系统图片选择器和系统相机返回结果，未拍摄真实场景。安全检查针对本应用及弹窗的标记配置，不作为系统采集遮挡效果的验收结论。
- 原正式应用数据未操作；仅安装、运行独立 `.qa` 包。真实相机拍摄质量及其他型号相机应用尚未逐机验收。

日志位于 `.local/verification/`，Android JUnit、Lint 报告位于 `android/app/build/`。本地截图使用虚构账号和公开标准测试密钥。

## 交付

本地交付目录为 `dist/`，包括 Windows 便携 ZIP、Android APK、完整源码 ZIP 及 SHA-256 清单。依赖组件和许可证见 `THIRD_PARTY_NOTICES.txt`、`third_party/zxing/` 和 Android APK 内 assets。

Windows 使用内嵌 ZXing.Net 0.16.11，保持单 EXE 可运行。Android 使用 ZXing core 3.5.4 与 AndroidX core 1.17.0，首次源码构建需要下载依赖，缓存后可离线构建。

本版本尚未提交、推送或发布 GitHub Release。
