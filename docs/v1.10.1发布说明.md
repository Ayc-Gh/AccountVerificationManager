# 账号验证管家 1.10.1

Windows 10/11 和 Android 8.0 及以上系统可使用此版本。Windows 用户退出旧程序，解压新版便携包并运行即可。

## Android 旧版用户迁移

原发布私钥已丢失。1.10.1 沿用包名 `cn.local.accountmanager`，启用新的正式签名。Android 会拒绝把 1.10.1 直接覆盖安装到 1.10.0 或更早版本之上。**请在卸载前备份，需要保留的本机历史会随卸载一并删除。**

1. 在旧版中打开历史管理，选择加密文件导出，勾选需要保留的全部记录。若旧版没有导出功能，可先用同一旧证书签名的 1.10.0 覆盖升级。[旧版 1.10.0 APK](https://github.com/Ayc-Gh/AccountVerificationManager/releases/download/android-v1.10.0/AccountVerificationManager-android-v1.10.0.apk)
2. 设置备份密码，把 `.avmx` 保存到下载目录或其他卸载后仍可访问的位置。确认文件已保存、密码可用后再继续。CPA 和 sub2api JSON 用于导出登录结果；恢复历史需要 `.avmx`。
3. 卸载旧应用，安装 1.10.1。在新版历史管理中导入刚保存的文件，输入备份密码，核对恢复的记录。使用 Android 自动填充的用户可在系统设置中重新启用该服务。

## 修复

- Windows 能重新打开从 Android 导入的、含受支持长字段的历史记录。打开多个窗口时，复制凭据或更新 HOTP 计数会核对最新记录。
- Android 在用户拒绝网页授权后显示实际原因。清空历史后，即使切到后台再返回，也会清除原记录关联的结果和复制入口。
- Android 在导出 CPA 或 sub2api JSON 时旋转屏幕，仍能按原格式完成写入并继续导出。在系统选择器前台发生进程回收时，新页面会提示登录结果失效，并允许重新登录。
- Android 构建采用 Gradle 9.9.2、AGP 9.5.2 和 AndroidX Core 1.19.1，最低版本为 API 26。修正了 Windows 中文路径单测与 Gradle 配置缓存的兼容问题。
