# 账号验证管家 1.7.0 历史记录命名

Windows 与 Android 都可在历史列表中点击“命名”或“改名”，为记录设置独立名称。名称最多 40 个字符，支持中文，保存时去掉首尾空白；留空保存可恢复默认显示。命名后仍展示原账号或原默认身份，方便核对。

名称只作显示备注，不改变账号、密码、密钥或验证码参数，也不混入复制的登录信息。命名不改变识别时间或列表顺序；再次识别同一条记录会保留名称并按既有规则置顶。取消编辑不保存。

## 持久化和兼容

两端的名称随历史一起在本机加密。新历史明文封装写入版本 3，兼容读取版本 1 和版本 2，旧记录默认没有自定义名称；命名或再次保存时升级格式。保留最近十条、损坏历史不被隐式覆盖等既有行为。

Windows 的命名操作在互斥锁内重读最新记录后写入，保留其他窗口修改及 HOTP 计数器；HOTP 递增时保留名称。Android 命名与原有存储操作共用串行队列和原子写入。新版保存历史后，旧版应用不能读取 v3 格式，请继续使用 1.7.0 或后续版本。
