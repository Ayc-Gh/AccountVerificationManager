# 1.7.2 Windows 改名弹窗

2026-11-16，优化 Windows 历史记录的命名与改名弹窗。主窗口继续采用 1.7.1 的紧凑布局。

弹窗使用与主界面一致的浅色背景、圆角记录卡片、输入框和按钮。标题区、当前记录、名称输入和底部操作分开排列，当前记录过长时省略显示；输入时实时显示字数。保存按钮使用蓝色，取消按钮使用白色；名称留空时按钮提示“恢复默认”。

打开时自动聚焦并选中已有名称，支持 Enter 保存、Esc 取消。名称仍最多 40 个字符，保存时去掉首尾空白，留空恢复默认名称。保存失败在输入框下方显示错误，保留编辑内容供重试，编辑后清除上次错误提示。

## 验证与范围

- Windows 3,858 项核心、83 项智能解析、16 项二维码、51 项加密历史、84 项界面检查通过，合计 4,092 项。
- 本轮增加 11 项弹窗检查，覆盖自动聚焦、字数更新、控件布局、Enter 保存及加密持久化、Esc 取消、写入失败保留原历史及输入、清除旧错误、留空恢复默认。
- 使用独立 QA 副本与虚构记录，实际打开弹窗检查排版和占位提示，并点击取消返回历史。保存及失败重试由上述集成检查验证。未读写正式历史，也未关闭当前运行的旧版程序。
