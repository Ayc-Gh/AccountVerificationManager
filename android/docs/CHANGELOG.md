# Android 更新记录

## v1.8.0 · 2026-11-16

- 新增“更换 2FA”，保留账号、密码、历史名称、时间及顺序；支持新旧验证码复制、粘贴、拍照和上传二维码。
- 新密钥或 URI 可先预览，确认后替换原记录；失败、取消及过期草稿不会覆盖原记录。
- 支持账号记录末项 URI，以便更换后保留算法、位数、周期和发行方；加密历史仍使用 v3 格式。
- 更换草稿在配置变更时仅通过内存保留，弹窗和复制延续应用端安全配置。
- versionName 1.8.0、versionCode 10800，保持原签名；34 组单元测试和 107 项真机回归通过。

## v1.7.0 · 2026-11-15

- 历史列表增加“命名 / 改名”；最多 40 个字符，留空恢复默认，取消不保存。
- 名称随历史加密保存，重新识别同一记录保留名称；保留原账号、参数、时间及排序。
- 历史明文格式升级为 v3，兼容读取 v1/v2；命名弹窗沿用应用端安全保护。
- 与 Windows 同步版本号为 1.7.0，versionCode 为 10700，沿用原发布签名。
- 28 组单元测试、88 项独立 QA 真机回归检查通过；当前为本地交付。

## v1.6.0 · 2026-11-15

- 与 Windows 同步用户可见版本号为 1.6.0，versionCode 为 10601。
- 增加“拍照识别二维码”和“上传二维码图片”，本机解码纯密钥和标准 TOTP URI，沿用验证码、复制与加密历史。
- 支持图片旋转、反色与同图多个有效二维码的选择；取消保留当前结果，失败停用旧复制按钮。
- 按用户最新要求恢复主窗口、二维码导入和应用弹窗的防截图/录屏保护；Android 13+ 禁用最近任务截图，恢复敏感剪贴板标记。
- 23 组单元测试、76 项独立 QA 真机回归检查通过，保持原发布签名。
- 当前为本地交付，尚未发布 GitHub Release。

## v1.1.0 · 2026-11-15

- 解析入口升级为“智能识别解析”，自动区分账号记录、纯 Base32 2FA 密钥和 Authenticator TOTP URI。
- URI 读取账号、发行方、密钥、SHA1/SHA256/SHA512 算法、6/8 位及实际周期；默认参数仅在 URI 省略时采用。
- 按实际参数刷新验证码和倒计时，新增规范化 URI 复制。
- 无账号或密码时隐藏相应字段，主页面与历史复制均只使用真实字段。
- 历史保留输入类型及 URI 参数，支持重启和旋转恢复；读取兼容 v1.0.0 历史格式和原加密密钥。
- 增加 RFC 三种算法标准向量、URI 编码与错误输入、历史迁移和真机交互验证。
- APK 沿用原发布签名，versionCode 从 1 升至 2，可覆盖升级。

## v1.0.0 · 2026-11-15

- 发布 Android 原生版：账号分隔、默认 TOTP、逐项复制、最近十条加密历史。
