# 原项目理解与 Android 功能对应

分析日期：2026-11-14。参考同仓库 Windows 版 v1.4 的功能演变，以及 `Core.cs`、`History.cs`、`Program.cs`、`Tests.cs`、`HistoryTests.cs` 和使用说明。

## 需求演变

1. 初始：拆分账号、密码、Base32 2FA 密钥，实时验证码，逐项一键复制。
2. v1.1：解决两处分隔符数量不同及密码末尾 * 被误切的问题。
3. v1.2：自动识别连续至少三个符号；保留手动按字面匹配。
4. v1.3：优化界面，突出验证码、倒计时、自动/手动切换和复制反馈。
5. v1.4：命名为“账号验证管家”，持久保存最近十条历史，点击恢复及快捷复制。

## 关键行为

| 原项目行为 | Android 对应 |
| --- | --- |
| 输入账号、密码、密钥的一条记录 | 原生多行文本框接受粘贴，但解析拒绝实际多条记录 |
| 自动标点/符号识别 | 按 Unicode 码点扫描连续至少三个标点或符号；支持表情 |
| 重复符号优先 | pass*----- 保留 *；混合符号无重复组时使用整个串 |
| 第一处与最后一处切分 | 密码内部出现的类似分隔符保持原样 |
| 手动分隔原样匹配 | 单字符、多字符、文本、空白、正则特殊字符均按字面匹配 |
| 密钥标准 Base32 | 先验证填充和末尾未用位，再去掉填充存储；支持小写和分组空白 |
| RFC 6238 TOTP | HMAC-SHA1 / 6 位 / Unix 时间 / 30 秒 |
| 动态验证码倒计时 | 前台每 200ms 根据系统时间更新，跨周期重算；后台停止定时器 |
| 复制时重新算验证码 | 主页面及历史快捷按钮均在点击时计算 |
| 输入变更清旧结果 | 修改内容、模式、手动分隔均清除结果和禁用复制 |
| 完整复制结果 | 主页面四行含密钥，历史整组三行不含密钥 |
| 最近十条记录 | 相同账号+密码+规范化密钥视为重复、保持记录 id 并置顶、超限淘汰最旧 |
| 历史恢复精确内容和模式 | 直接按字段恢复结果，避免再次自动解析歧义；还原原始分隔符 |
| 本机加密持久化 | DPAPI 替换为 Android Keystore AES-256-GCM；原子密文写入 |
| 损坏历史不覆盖 | 每次记录先读取验证；失败显示提示并保留原文件；明确清空可恢复 |
| 清空当前与清空历史分开 | 清空历史需要确认，当前输入和结果保留 |

## 手机端适配

- 桌面横向三栏改为单列滚动和“解析 / 历史记录”底部切换。
- 验证码卡片突出当前六位数字、倒计时和复制；密码默认隐藏。
- 网络、存储、相机等权限均不申请；不自动读取剪贴板，只在点击粘贴时读取。
- 处理全面屏状态栏、手势导航和键盘 Insets，适配浅色/深色主题。
- 磁盘和 Keystore 操作由进程内单一后台队列执行，界面不会等待磁盘。
- 配置变更仅在内存保存当前结果；不将凭据放入 Activity 保存状态或普通配置文件。
- 正式包与测试包分别签名、分别存储，验收只使用虚构数据。

## 有意保留的功能边界

v1.0.0 保持原项目的单条解析和默认 TOTP 参数。Windows 历史绑定 Windows 用户，不能复制密文到 Android 使用。Android 安装包兼容 8.0+，不是 iOS 安装包。

## v1.1.0 智能识别扩展

在保留原账号分隔行为的基础上，新增独立 Base32 密钥与 Authenticator TOTP URI。URI 解析账号和发行方，实际算法、位数、周期贯穿验证码计算、界面倒计时、复制、历史去重、持久化及旋转恢复。缺少的账号或密码不生成占位凭据，也不参与复制。

历史明文格式写入版本 2，同时兼容版本 1；外层认证加密格式、AAD 和 Keystore 别名不变，因此直接覆盖升级后可读取旧记录。不同类型或验证码参数会保留为不同记录。

HOTP、批量迁移 URI、扫码和云同步仍不在本版本范围内。
