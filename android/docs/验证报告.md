## 兼容边界

已验证 Android API 37 真机浅色界面；其他版本和深色布局未逐机测试。支持单条 TOTP URI（SHA1/SHA256/SHA512、6/8 位、正整数秒周期），不支持 HOTP、批量迁移 URI 或扫码。

Android v1.0.0 历史沿用加密密钥及封装格式，升级可保留；Windows DPAPI 历史不能直接导入。请保持手机时间准确。
